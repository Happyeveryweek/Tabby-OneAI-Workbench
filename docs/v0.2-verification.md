# v0.2 Codex 工作台验收

在 Windows 的官方 Tabby `1.0.238.0` 通过插件目录加载 `tabby-oneai-0.2.0.tgz`。测试使用独立 Tabby 配置和测试 `CODEX_HOME`。

| 场景 | 结果 |
| --- | --- |
| 原生终端 | 实机打开两个原版 Codex 交互进程，从项目树切回同一进程。PowerShell 7、WSL 工作目录、Tabby 原生分屏、独立退出和项目记录持久化通过 v0.1 回归。 |
| 账号隔离 | 在工作台添加测试账号，新任务执行时收到对应的 `CODEX_HOME`。顶部额度随所选账号变化。 |
| 会话归属 | 通过真实 Tabby 终端接收测试会话标题，按会话 ID 绑定最近用户消息、模型、推理档位与累计 Tokens。 |
| 历史与恢复 | 合并本地日志与 Codex 分页历史，按标题搜索，恢复时检查原目录、账号和会话 ID，验证分页会话的最新消息。 |
| 状态栏 | 显示 5 小时和 7 天剩余额度，用测试响应验证手动刷新和当前会话的 Tokens。 |
| 用量 | 按账号、模型统计本周请求、会话和 Tokens，显示近 26 周活动。验证账号筛选和重复事件去重。 |

![Tabby 内的项目树与 Codex 顶部状态栏](codex-v0.2-status.png)

本机 Windows 和 WSL 的原版 Codex 均通过 App Server 握手和历史读取测试。额度刷新、会话摘要、精确恢复参数和统计使用受控数据验证。真实登录账号的在线额度、真实历史对话恢复和长时间使用留待试用验收。本周统计和热力图的覆盖范围是当前账号能读取的本地会话日志。

## v0.2.1 侧栏历史回归

在同版本的官方 Tabby 加载 `tabby-oneai-0.2.1.tgz`。通过受控数据验证新添加项目与重开窗口后自动显示最近会话、账号和目录归属、读取历史期间不启动终端、点击恢复和去重。原有历史页恢复和用量流程一并通过。对本机 Windows 默认 Codex 目录进行了只读核对，`dentist_app` 和 `TabbyOneAi` 都能匹配到会话。

实现参考 [OneAI 用量统计源码](https://github.com/Qingxuan365/oneAI/blob/main/src/main/usage-stats.ts)、[OneAI 账号环境源码](https://github.com/Qingxuan365/oneAI/blob/main/src/main/account-env.ts) 和 [Codex v0.170.0 App Server 文档](https://github.com/openai/codex/blob/rust-v0.170.0/codex-rs/app-server/README.md) 。

## v0.2.2 工作台界面回归

- 在官方 Tabby 独立窗口验证选择、取消、重复选择文件夹的结果。Windows 选择器的返回值使用测试替身，WSL 目录实际校验。
- 项目「+」从当前文件夹直启已检测到的 CLI 或系统终端，自定义命令使用指定的工作目录。复用 OneAI 的品牌图标，在菜单、侧栏会话与原生标签中验证渲染。Codex、OpenCode、Pi 和 Antigravity 的测试终端使用受控命令输出。
- 原生标签随退出更新色条，分屏跟随焦点切换 CLI 图标和状态。模型、额度和 Tokens 在下方详情栏显示。
- 验证设置中切换 Tabby 深浅主题、账号目录与 CLI 检测。历史抽屉按日期分组、标记已打开并在恢复后关闭。用量弹窗显示本周总计、账号和模型明细及热力图，筛选后仍保留正确的请求去重。
- 使用本机 PowerShell 7 和 WSL 回归工作目录、任务切换、退出、分屏和重启后的项目持久化。

## v0.2.9

在官方 Tabby `v1.0.238` 的隔离配置中载入本地插件包，使用受控会话和进程验证下列场景。

| 场景 | 验证结果 |
| --- | --- |
| 项目树 | Windows 与 Ubuntu WSL 仓库的分支标签左边缘对齐。长项目名和分支名省略显示，保留完整悬停文字。侧栏挂载后隐藏工具栏入口，模拟挂载失败后仍能打开工作台。 |
| 外观 | 在 Tabby 中即时切换 6 套护眼配色、10 套编辑器配色及随系统模式。验证设置窄窗口滚动、字体搜索和键盘选择，以及重启后保留和恢复跟随 Tabby。 |
| CLI 环境与目录 | 显示 Windows 生效的 Codex 数据目录。添加两个包含空格的 Claude 目录后自动扫描，保留不同目录中同 ID 的会话。切换默认启动目录后，恢复历史仍带原 `CLAUDE_CONFIG_DIR` 和会话 ID。Ubuntu WSL 的 Launch 参数验证通过，带空格和中文的路径可作为完整变量值传入。 |
| 活动状态 | Codex 通过原生终端标题、Antigravity 通过官方状态栏数据、OpenCode 通过终端输入区更新就绪、运行和等待。Pi 通过终端输入区更新就绪和运行。顶部和侧栏同步。 |
| Antigravity 用量 | 在 Hydrogen、Argon 和第三方 Claude 间切换，验证状态栏选取当前模型对应的额度及重置时间，并保留 CLI 原有底部状态栏。 |

Codex、Antigravity、OpenCode 和 Pi 的状态由原生终端与受控数据回放验证。Claude Code 和 Kimi Code 在本机配置的 CLI 路径中未检出，当前支持进程状态。Claude 的会话目录扫描与恢复使用本地样本验证。

## v0.2.11

本地插件包通过 TypeScript 构建及官方 Tabby `v1.0.238` 隔离配置回归。CLI 会话和状态使用受控样本，目录探测及添加项目同时覆盖 Windows 和 Ubuntu WSL。

| 场景 | 验证结果 |
| --- | --- |
| 外观与项目入口 | 工作台字号实时跟随 Tabby 全局默认字号。自定义字号即时生效、跨重载保存，切回跟随后保留上次自定义值。24 px 时窄窗口内容可滚动。移除工作台「终端」分类后，添加项目仍可选择 PowerShell 7 文件夹选择器或 WSL 路径。 |
| CLI 环境与目录 | Codex 已存在的目录显示「存在」。Claude 和 Kimi 的默认路径可显示「不存在」。目录页移除登录操作，Claude 多目录与原目录恢复回归通过。 |
| 历史抽屉 | 右侧抽屉从会话状态栏下沿开始，避开窗口控制区域。提示词展开、右键复制和会话归属回归通过。 |
| 用量 | Codex 单会话的两个模型分别显示。切换到本周排除较早记录，切换模型同时更新热力图和明细。切换会话与项目时面板尺寸一致。 |
| Claude Code | 通过官方状态栏数据验证模型、上下文比例、5 小时和 7 天额度，并从会话日志读取去重后的累计 Tokens。验证从历史恢复及新启动时关联正确的日志。 |
| Kimi Code | 新版会话索引与日志样本可定位和恢复会话，显示模型及累计 Tokens。旧版日志样本验证上下文比例与用量去重。新版上下文和额度缺少已接入的来源时显示「—」。 |
